## 5. Verification gotchas (each cost real time — check before trusting)
- **`origin/*` tracking refs are STALE by construction** (SSH `origin` is interactive-only; agents
  push/fetch via `https://github.com/arttarawork/tinygrad.git`, which never updates them). `git status`
  showing `memory [ahead N]` is NOT a backup gap. Ground truth: `gh api repos/arttarawork/tinygrad/branches`.
  **Never branch off `origin/master`.**
- **`pgrep -f` self-matches** shell/command text (incl. your own scripts' contents): verify matched PIDs
  via `ps -o command= -p <pid> | grep '^/Applications/TinyGPU.app'` before believing a server count.
- **A zsh wrapper shows 0% CPU while its python child works at 100%** — `pgrep -P <wrapper>` first.
- **The bench harness prints `bytes-read-per-step / total-allocated-across-ALL-devices`** (`llm/cli.py:201`),
  not used-of-budget. Verify any readout against source before it reaches the docs.
- zsh traps: `/usr/bin/log` (not the `log` builtin); `${B}:path` (a bare `$B:path` triggers the `:t`
  modifier); macOS has no `timeout` binary.
- **A pipeline's exit status is its LAST command**: `pytest … | tail -1` returns tail's 0, so `set -e`
  and `&&` sail past red tests (this shipped failing tests to PR #8 once, and masked gates twice more).
  Capture `RC=${pipestatus[1]}` (zsh) or run the command unpiped and read the log after.
- Evidence that survives panics/reboots: the unified log (`/usr/bin/log show --predicate 'eventMessage
  CONTAINS[c] "tinygpu"'` — DEXT logs opens/cfg-writes/resets/DMA-maps; `--end` may be ignored, filter by
  date prefix) and `~/.claude/projects/-Users-artur-Documents-tinygrad/<session>.jsonl` (+`/subagents/`).
