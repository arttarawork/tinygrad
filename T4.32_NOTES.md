## Step 7 — T4.37 healthy-state PCI sanity (no fault induced)

Per the brief, this was read **inside Step 3's re-run process**, immediately after its decode loop
finished and before the process exited (avoids opening a second fresh device connection, which
would trigger its own WPR2-driven reset per Step 2's analysis and wouldn't test "this process's"
state). Script: `Device["NV"].iface.pci_dev.read_config(pci.PCI_COMMAND, 2)`.

```
PCI_COMMAND=0x7 MASTER_bit=0x4 MASTER_set=True
```

`0x7` = I/O space + memory space + bus master all enabled. **MASTER is correctly SET on a healthy
device**, consistent with the T4.37 code path: `PCIIface.device_fini()` only clears `MASTER` when
`self.dev_impl.is_err_state` is true (`ops_nv.py:857-859`); this run never entered an error state,
so bus-master was correctly left untouched. No fault was induced, none occurred — this checks the
*inverse* of T4.37's own verification (which forced a fault and checked the bit went to 0); together
they cover both branches of the guard.
